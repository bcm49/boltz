We competed in the allosteric/orthosteric challenge. We run boltz with 1 diffusion sample, then run fpocket on the prediction to enumerate and rank the pockets, then we use the fpocket output to find the pocket centroids and create a receptor for docking with a box centered on the pocket centroid. For each of the top 4 pockets according to fpocket's score, we run autodock-vina to dock the single ligand into the receptor. Each docking creates 2 binding modes. We used RDKit to generate the initial conformer. Finally, we rank the 8 total conformations by their autodock-vina-outputted free energy.
